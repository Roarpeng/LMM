# X 双驱双速度（g 0.26）设计

日期：2026-08-05  
状态：**0.59 单沿起步 + SM3 斜坡 + Halt 对称减速**（0.34 双速度 + 视觉走直基础上演进）  
基线：0.31（不改已有 XML）；0.32/0.33 保持原文件  
交付：`LMM_g_0.34.xml` … `LMM_g_0.59.xml`

## 动机

- 现场视觉航向纠偏是速度域外环；M1 CSP + M2 CSV 带宽不对称，换向/松手行为不一致。
- 0.25 已消报警，但仍有「一方向走完立刻反方向不动」「松手仍溜」。
- 决策：不再纠结混架构，改为 **双速度指令**。

## 目标

1. M1/M2 均用 `MC_MoveVelocity`（同构），废除 M1 `MC_Jog`。
2. 换向：任一侧符号变化 → 撤 `Execute` 一拍再重触发（对齐 `FB_Servo`）。
3. 松手：`eMode=0` → 立刻撤双轴 `Execute` → `MC_Halt` 减速（禁止零速保持 Execute）。
4. 视觉：保留 `rHeadingErr * rKpTrack` 差速；同步 trim 轻量（P，I/D=0，同号钳位）。
5. SoftHold：保持调节器；仅表示空闲（无速度 FB），退出沿 Reset。

## 非目标

- 本轮不改设备树 `0x6060`（若现场已是线轴 finite，SoftMotion 速度 FB 可用；真 CSV 驱动模式可后补）。
- 不恢复 Virtual / GearIn。
- 不改 Y/Z/R、HMI 命令字。

## 速度合成

| 模式 | rVelCmdM1 | rVelCmdM2 |
|------|-----------|-----------|
| Jog/MoveRel | ±V | V1 − 2·trim_vis + trim_sync（同号钳位） |
| SpinL/R | ±Vspin | −V1 |
| 停止 | 0 | 0 → Halt |

## 0.34 双速度走直

M1/M2 必须同为速度模式（视觉外环差速）。摇晃来自**两侧独立斜坡 + 编码器同步与视觉抢方向**。

- 共用一条基速斜坡 `rVelAppl`，再 `V1/V2 = Vappl ± 视觉`
- 编码器同步：到速后才开、Kp 很小；`|视觉trim|` 大时再压到 25%
- 保留：Reset 仅手动、松手 Halt、换向撤 Execute、Acc 跟随 HMI

## 0.58 阶梯爬速 + 每步重触发（起步消往复）

**现象**：每次启动运动（点动/自动走距），X 沿前进方向前后冲 3 次左右（约 3s）才按命令走。只有 X 轴。

**根因**：
- X 双驱是设备树里仅有的 CSV（0x6060=9）轴，速度指令直进驱动速度环；
- 起步 = 速度阶跃（HMI_rAccX=25 → 0.4 m/s 在 16ms 内到位），激起双电机耦合龙门的
  ~1Hz 纵向共振（3 次冲/3s）；
- 0.53 的 PLC 阶梯爬速本可消过冲，但本机 `MC_MoveVelocity` 仅在 **Execute 上升沿**
  采样 Velocity——Execute 保持时改输入不生效，首拍 ~0 被锁死（"不过冲也不走"）。

**方案（0.58）**：
1. 恢复 `rVelSlewM1/M2` 阶梯爬速，每周期按有效斜率逼近目标；斜率 = 用户 Acc/Dec
   钳制在 [0.05, 1.0]（防 100 兜底变回阶跃）。SM3 Acc 抬到 ≥10 只负责跟梯。
2. **爬坡期 Execute 每步重触发**（OFF/ON 交替一拍，复用换向重触发的机制），
   上升沿重采样当前爬速——这是 0.53 缺失的一环。
3. 松手/到位对称处理：先阶梯降到 ~0 再撤 Execute → Halt 脉冲（急停/停止仍走 Stop 不斜坡）。
4. MoveRel 提前减速：剩余 ≤ slew²/(2·Dec) 时进入减速斜坡，走距精度保持；
   到位锁（xDecelDone）禁止停稳后重新爬目标。
5. 点动/旋转/自动共用同一斜坡。

**现场参数建议**：HMI_rAccX / HMI_rDecX 设 0.3~0.8（0.4 m/s 时斜坡 0.5~1.3s），
超过 1.0 被钳制。视觉未接时 rTrim 恒 0，斜坡即全部起步曲线。

**验收（0.58）**：
1. 每次点动/自动起步不再前后冲，直接平稳走。
2. 松手平滑减速停，不溜车；急停仍立即 Stop。
3. MoveRel 走距误差不回退（提前减速 + 到位锁）。
4. 换向（JOG+ → JOG−）与旋转模式不受影响。
## 0.59 单沿起步 + SM3 斜坡 + Halt 对称减速（0.58 每步重触发废除）

**现场反馈（0.58，acc=dec=0.8）**：
- 起步仍快速运动 2 次（每次约 1s），第三次非常慢，然后停止不动；
- M2 明显比 M1 运动速度慢。

**根因**：
- 0.58 爬坡期 Execute 每 4ms 重触发一次（250Hz 沿风暴）。每个上升沿重拉速度档，
  反复踢起龙门 ~1Hz 共振（1s 级前后冲）；连续重触发最终激起 FB/驱动 Error →
  xFault 闭锁 → 轴停死（"第三次慢 + 停止不动"）。
- 两侧 FB/驱动接受上升沿的时刻不一致（Busy/带宽差异）→ M2 漏沿 → 爬速锁存落后
  → M2 明显慢。

**方案（0.59）**：
1. 起步只发一个 Execute 上升沿：一次写入最终目标速度 + 钳制用户 Acc/Dec
   （[0.05, 1.0]，HMI 25/100 兜底不再 16ms 阶跃），SM3 自带斜坡 0→目标
   （0.8 → 0.5s）。0.54 已证明单沿可行，0.55/0.56 已修掉当时的过冲根因
   （PRG_Logic AxisCmd 空窗、Power.Status 闪烁清 xStartReady）。
2. 稳态 trim/sync 更新走限频重触发：仅非爬坡期（xRampLock 已放）+ 两侧到速 +
   目标与锁存差 ≥0.004，且距上次 ≥200ms。无视觉/同步漂移时永不触发——
   起步到停车全程一个沿。
3. 减速统一 Halt（Dec = 钳制用户 Dec，与起步斜坡对称）；MoveRel 提前减速改为
   剩余 ≤ v_act²/(2·Dec) 时发一次 Halt 脉冲；到位锁 xDecelDone 保持。
4. 删除 PLC 阶梯爬速（rVelSlew）机制：SM3 的 Acc/Dec 剖面就是斜坡，
   不再需要每步重采样。

**验收（0.59）**：
1. acc=dec=0.8 点动/自动起步直接平稳走（~0.5s 爬坡），无前后冲。
2. M1/M2 速度一致；M2 不漏沿。
3. 松手/到位 Halt 对称减速停，不溜车；急停仍立即 Stop。
4. 换向、旋转、MoveRel 走距精度不变。

## 验收

1. JOG+ 直行不左右摇晃。
2. JOG+ → 松手停 → JOG− 立刻反走；反之亦然。
3. 松手后双轴减速停，不继续溜。
4. 无位置误差超限报警。
