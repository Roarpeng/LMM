# WebHMI v3 —— 工业设备操作台 UI 设计

日期：2026-09-12
状态：设计定稿（UI 重构；通讯/控制层不变）
范围：`web/live` 前端信息架构与视觉；**不改** Gateway / Modbus / PLC / WebSocket 契约。

## 0. 不可违反的原则

- **通讯层不动**：浏览器 ↔ WS/JSON ↔ gateway ↔ Modbus TCP ↔ PLC，沿用 `t:"w"/"s"/"ping"/"pong"/"hello"/"lease"/"wack"`。
- **绑定不丢**：所有 GVL 命令/状态字段在页面有入口；`web-client` 测试的 map 全覆盖必须保持。
- **安全交互保留**：单写者租约、断线安全、急停请求、停止/复位、按住点动、心跳/看门狗。
- **不做 SaaS 风**：禁用大面积渐变、毛玻璃、大圆角、重阴影、彩色卡片堆叠、炫技动画。
- **颜色只表达状态语义**，不做装饰。

## 2. 页面

| 页 | 主角 | 内容 |
|----|------|------|
| 总览 | 设备状态 + 机身动画 | 状态大字、X/Y/Z/R 大数字、当前任务/步序、报警摘要；80% 停留页 |
| 自动 | 任务执行 | 步序进度条、启动/中止、参数摘要、Busy/Done |
| 手动 | 示教器 | 十字点动（按住动/松开停）、速度、Home、使能/停止 |
| X双驱 | M1/M2 | 双速大数字、ΔV/ΔX、SYNC 状态、速度趋势（本项目招牌页） |
| 力传感 | 力 | 当前力大数字、峰值、设定、柱状表、力引导/去皮/模拟 |
| 趋势 | 曲线 | M1/M2 实际+指令、同步误差、力；时间窗 5s/30s/1min/5min |
| 报警 | 报警中心 | 活动报警 + 历史（码/名称/时间/状态），灯位排 |
| 调试 | 工程 | 寄存器表、命令台、/health 诊断、快照/CSV、日志 |
| 系统 | 通讯 | PLC/Gateway/WS 角色、模式、host/port、RTT、Lease、心跳、Ack、版本 |

### 急停 / 报警 Overlay
`ESTOP` 或报警活动时，主视图覆盖高对比提示（红），显示报警码/名称/处置与「复位设备」。

## 4. 组件

- **StatusChip**：状态语义色 + 文本，唯一的状态权威。
- **Metric / BigNumber**：标签 + 等宽大数字 + 单位；位置/速度为等宽。
- **DataCard**：1px 边框、无渐变；左上角小标题。
- **HoldButton**：`pointerdown/up` 按住动、松开停；`.hold.active` 高亮。
- **AlarmRow**：码 / 名称 / 时间 / 状态（活动/已恢复）。
- **RegTable**：等宽、粘性表头。
- **NavItem**：图标 + 文本；active 左侧 3px 强调条 + 面板底色。

## 5. UI 数据层（HMI Store）

页面**不直接** `ws.send`。统一走：

```
page  ──▶  HMI Store (state / cmd / 方法)  ──▶  WebSocket
```

- `HMI.state`：最新状态镜像（`t:"s"`）。
- `HMI.cmd`：命令镜像。
- 方法：`HMI.patch(obj)`、`HMI.jog(act,on)`、`HMI.pulse(obj)`、`HMI.setParam(key,val)`。
- 保留 `flush/patch/connect/bindParam` 名称与安全钩子（测试依赖）。
