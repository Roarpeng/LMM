# 视觉纠偏 — Modbus TCP

## 地址

| 角色 | IP | 端口 |
|------|-----|------|
| 视觉工控机（服务端 / 从站） | `192.168.1.90` | `502` |
| PLC / Gateway（客户端 / 主站） | `192.168.1.88` | — |

Unit ID = `1`。**PLC（实际由 Gateway 代发）去连视觉**，视觉只监听、等着被读。


## 协议

- **Modbus TCP**
- 读：`FC03`（读 Holding）
- 周期：20～50 ms 读一次
- 视觉侧：丢目标时把误差写成 `0`，心跳寄存器照常更新

视觉只提供下面 2 个 Holding，不要做成再去写 PLC。

## 字节

Holding **0、1** = 航向误差 `heading_err`（弧度）

- 有符号 32 位整数 = `round(弧度 × 1000)`
- **高字在前**：0 = 高 16 位，1 = 低 16 位
- 网络字节序：每个 WORD 高字节在前

| 弧度 | 32 位 | Holding 0 | Holding 1 | 线上 4 字节 |
|------|--------|-----------|-----------|-------------|
| `+0.012` | `12` | `0x0000` | `0x000C` | `00 00 00 0C` |
| `0` | `0` | `0x0000` | `0x0000` | `00 00 00 00` |
| `−0.012` | `−12` | `0xFFFF` | `0xFFF4` | `FF FF FF F4` |

符号：车头偏左写正，偏右写负。M1 左电机、M2 右电机。
