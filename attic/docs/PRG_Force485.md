# PRG_Force485 — SM1001 使能 + 读回文探测

## 使能 / 回文（按需求）

```
关从站 → 使能 SM1001 → 发读 → 有回文则成功停止
                ↑______________| 无回文
最多 3 次无回文 → 报警 1006
```

### 何谓「有回文」

组态 FC03 把结果写入 `Force_wInRaw`。探测时先把 `Force_wInRaw` 异或破坏，再等通道写回；**写回后与破坏值不同 = 收到回文**（力值恒定也能判成功）。

可选：读通道触发绑 `Force_xReadTrig`（上升沿）。若已是 **循环读**，不绑也可，靠循环写回判定。

### 成功后

`iSlaveStep=10`：`SM1001` 保持 TRUE，**不再重试使能**；继续换算/去皮/力引导。
